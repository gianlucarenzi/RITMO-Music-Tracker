# RITMO 2.8 – songs in C programs with cc65, the songs and instruments in every release, and a busy indicator

RITMO 2.8 adds a third assembler format to the "Relocatable ASM" export, for ca65, the assembler of cc65, together with a complete example of the RMT player in a C program. Every release now has the example songs and instruments and the user manual as downloads of their own, and an export that takes more than a moment shows that RITMO is working instead of looking frozen. Every module saves and exports exactly as before.

## What changed

- **Songs in C programs built with cc65.** File > Export as... > "Relocatable ASM for RMTPlayer" has a third assembler format, **CA65 (cc65)**, next to Atasm and Xasm (script: `asmformat=ca65`): the module is a `.proc` named by its start label, exported and ready for ld65. Every module of the repository exported this way and assembled by ca65 is the stripped module byte for byte (RITMO issue #5).
- **`asm/cc65-example`**: a complete example of a song played by the RMT player in a C program: the Patch16 player of `asm/ca65`, a small wrapper (`rmt_init()`, the player on the deferred VBI), a linker configuration with the memory layout, and a guide in its `README.md`. `make SONG=yourtune.rmt` builds an XEX that plays your song, and a downloaded RITMO works for the export (`make RITMO=~/Downloads/Ritmo-2.8-x86_64.AppImage`). The manual has a section on it.
- **The songs and instruments in every release**: `Ritmo-Songs-and-Instruments-<version>.zip`, the same for every system. Until now none of the packages carried them, while the manual pointed to an "instruments folder of the program" that did not exist (RITMO issue #4).
- **The user manual in every release**, as `Ritmo-User-Manual-<version>.pdf`, the release candidates too (RITMO issue #4).
- **An export that takes more than a moment** (SAP-R, LZSS, SAP, XEX with the LZSS player, WAV) covers the window with grey and a spinner until the file is written: before, RITMO only looked frozen. Quick exports show nothing, and the files are the same byte for byte. `RMT_QT_BUSY=off` turns it off.
- **The manual**: two POKEYs have eight voices, not sixteen; where to find the songs and instruments; the CA65 format and the cc65 example; the busy indicator.
- **Inside**: RITMO builds with RtMidi 6.1, which moved its classes into a namespace; the release builds were adapted to the changes of the build machines (MSYS2 without RtMidi, macOS 15, Ubuntu 26.04).

As always, **please tell me how it works for you** by opening an [issue](https://github.com/gianlucarenzi/RITMO-Music-Tracker/issues). The whole list of changes is in the [change history](https://github.com/gianlucarenzi/RITMO-Music-Tracker/blob/master/doc/rmt_changes.md).
